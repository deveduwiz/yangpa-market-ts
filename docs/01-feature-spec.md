## 상세 기능 명세

### 1. 회원가입

**설명**: 새로운 사용자가 서비스에 가입한다.

**입력**
- 이메일 (필수, 50자 이내, 중복 불가)
- 이름 (필수, 50자 이내)
- 비밀번호 (필수)

**처리**
- 이메일 중복 확인
- 비밀번호 암호화 (bcrypt)
- 회원 정보 저장

**출력**
- 성공: 가입 완료 메시지
- 실패: 중복 이메일 오류

---

### 2. 로그인

**설명**: 가입한 사용자가 인증을 수행한다.

**입력**
- 이메일
- 비밀번호

**처리**
- 이메일로 회원 조회
- 비밀번호 일치 확인
- JWT 토큰 발급 (24시간 유효)

**출력**
- 성공: 토큰 반환
- 실패: 인증 오류

---

### 3. 상품 등록

**설명**: 판매할 상품을 등록한다.

**입력**
- 상품명 (필수, 50자 이내)
- 설명 (필수)
- 가격 (필수, 0 이상 정수)
- 사진 (필수, 1장)

**처리**
- 이미지 파일 저장
- 상품 정보 DB 저장
- 판매자는 토큰에서 추출

**출력**
- 성공: 등록된 상품 정보
- 실패: 입력값 오류

---

### 4. 상품 목록 조회

**설명**: 등록된 상품 목록을 페이지 단위로 조회한다.

**입력**
- 페이지 번호 (기본값: 1)
- 페이지 크기 (기본값: 10)
- 판매자 이메일 (선택)

**처리**
- 최신 등록순 정렬
- 페이지네이션 적용
- 찜 여부/찜 수 계산

**출력**
- 상품 목록
- 전체 개수
- 다음 페이지 존재 여부

---

### 5. 상품 상세 조회

**설명**: 특정 상품의 상세 정보를 조회한다.

**입력**
- 상품 ID

**처리**
- 상품 정보 조회
- 판매자 정보 조인
- 찜 여부/찜 수 계산

**출력**
- 상품 상세 정보

---

### 6. 상품 검색

**설명**: 상품명으로 상품을 검색한다.

**입력**
- 검색어
- 페이지 정보

**처리**
- 상품명에 검색어 포함 여부 확인 (LIKE)
- 결과 페이지네이션

**출력**
- 검색 결과 목록
- 검색 결과 수

---

### 7. 상품 삭제

**설명**: 본인이 등록한 상품을 삭제한다.

**입력**
- 상품 ID

**처리**
- 본인 상품 여부 확인
- 상품 삭제 (soft delete)
- 관련 찜 데이터 정리

**출력**
- 성공: 삭제 완료
- 실패: 권한 오류

---

### 8. 찜하기

**설명**: 관심 있는 상품을 찜 목록에 추가/제거한다.

**입력**
- 상품 ID
- 찜 추가/해제 여부

**처리**
- 찜 상태 토글
- 멱등성 보장

**출력**
- 현재 찜 상태
- 해당 상품의 총 찜 수

---

### 9. 찜 목록

**설명**: 내가 찜한 상품 목록을 조회한다.

**입력**
- 페이지 정보

**처리**
- 찜한 시간 역순 정렬
- 페이지네이션

**출력**
- 찜한 상품 목록

---

### 10. 마이페이지

**설명**: 내 정보와 활동 내역을 조회한다.

**표시 정보**
- 이름, 이메일
- 가입일
- 등록 상품 수
- 찜한 상품 수
- 내가 등록한 상품 목록

**기능**
- 로그아웃

---

### 11. 로그아웃

**설명**: 현재 세션을 종료한다.

**처리**
- 클라이언트에서 토큰 삭제
- 로그인 화면으로 이동
