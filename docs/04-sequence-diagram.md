# 시퀀스 다이어그램

주요 기능의 처리 흐름입니다.

## 1. 회원가입

```
Client              Server              Database
  │                   │                    │
  │ POST /sign-up     │                    │
  │ {email,name,pw}   │                    │
  │──────────────────>│                    │
  │                   │                    │
  │                   │ SELECT (email)     │
  │                   │───────────────────>│
  │                   │                    │
  │                   │    결과 (0건)      │
  │                   │<───────────────────│
  │                   │                    │
  │                   │ bcrypt.hash(pw)    │
  │                   │────┐               │
  │                   │<───┘               │
  │                   │                    │
  │                   │ INSERT user        │
  │                   │───────────────────>│
  │                   │                    │
  │                   │      성공          │
  │                   │<───────────────────│
  │                   │                    │
  │   201 Created     │                    │
  │   {member}        │                    │
  │<──────────────────│                    │
  │                   │                    │
```

## 2. 로그인

```
Client              Server              Database
  │                   │                    │
  │ POST /sign-in     │                    │
  │ {email, pw}       │                    │
  │──────────────────>│                    │
  │                   │                    │
  │                   │ SELECT user        │
  │                   │───────────────────>│
  │                   │                    │
  │                   │    user 정보       │
  │                   │<───────────────────│
  │                   │                    │
  │                   │ bcrypt.compare()   │
  │                   │────┐               │
  │                   │<───┘ 일치          │
  │                   │                    │
  │                   │ jwt.sign()         │
  │                   │────┐               │
  │                   │<───┘ token         │
  │                   │                    │
  │   200 OK          │                    │
  │   {token}         │                    │
  │<──────────────────│                    │
  │                   │                    │
```

## 3. 상품 목록 조회

```
Client              Server              Database
  │                   │                    │
  │ GET /sales        │                    │
  │ Authorization:    │                    │
  │ Bearer token      │                    │
  │──────────────────>│                    │
  │                   │                    │
  │                   │ jwt.verify()       │
  │                   │────┐               │
  │                   │<───┘ email         │
  │                   │                    │
  │                   │ SELECT sales       │
  │                   │ (with pagination)  │
  │                   │───────────────────>│
  │                   │                    │
  │                   │    sales[]         │
  │                   │<───────────────────│
  │                   │                    │
  │                   │ SELECT favorites   │
  │                   │ (for sale ids)     │
  │                   │───────────────────>│
  │                   │                    │
  │                   │   favorites[]      │
  │                   │<───────────────────│
  │                   │                    │
  │                   │ merge isFavorite,  │
  │                   │ favoriteCount      │
  │                   │────┐               │
  │                   │<───┘               │
  │                   │                    │
  │   200 OK          │                    │
  │   {documents,     │                    │
  │    count}         │                    │
  │<──────────────────│                    │
  │                   │                    │
```
