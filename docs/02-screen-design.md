# 화면 설계서

양파마켓의 화면 구성과 흐름입니다.

## 화면 목록

| No | 화면 | URL (웹) | 인증 |
|----|------|----------|------|
| 1 | 로그인 | `/sign-in` | - |
| 2 | 회원가입 | `/sign-up` | - |
| 3 | 상품 목록 | `/sales` | 필요 |
| 4 | 상품 상세 | `/sales/:id` | 필요 |
| 5 | 상품 등록 | `/sales/new` | 필요 |
| 6 | 찜 목록 | `/favorites` | 필요 |
| 7 | 마이페이지 | `/my` | 필요 |

## 화면 흐름도

```
[로그인] ←→ [회원가입]
    ↓
[상품 목록] ←→ [상품 상세]
    ↓              ↓
[상품 등록]    [찜하기]
    ↓
[마이페이지] → [로그아웃] → [로그인]
    ↓
[찜 목록]
```

## 화면별 상세

### 1. 로그인 화면

```
┌─────────────────────────────┐
│         양파마켓            │
├─────────────────────────────┤
│                             │
│  ┌───────────────────────┐  │
│  │ 이메일                │  │
│  └───────────────────────┘  │
│                             │
│  ┌───────────────────────┐  │
│  │ 비밀번호              │  │
│  └───────────────────────┘  │
│                             │
│  ┌───────────────────────┐  │
│  │       로그인          │  │
│  └───────────────────────┘  │
│                             │
│     계정이 없으신가요?      │
│        [회원가입]           │
│                             │
```

**구성 요소**
- 로고/서비스명
- 이메일 입력 필드
- 비밀번호 입력 필드
- 로그인 버튼
- 회원가입 링크

### 3. 상품 목록 화면

```
┌─────────────────────────────────────────┐
│ 양파마켓    목록  찜  마이    OOO님     │
├─────────────────────────────────────────┤
│ 상품 목록          [카드|리스트] [내 상품만] [상품 등록] │
├─────────────────────────────────────────┤
│ ┌─────────────────────────────────────┐ │
│ │ 🔍 상품명으로 검색               X │ │
│ └─────────────────────────────────────┘ │
├─────────────────────────────────────────┤
│                                         │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐  │
│  │  사진   │  │  사진   │  │  사진   │  │
│  │         │  │         │  │         │  │
│  ├─────────┤  ├─────────┤  ├─────────┤  │
│  │ 상품명  │  │ 상품명  │  │ 상품명  │  │
│  │ 가격    │  │ 가격    │  │ 가격    │  │
│  │ 판매자♡│  │ 판매자♡│  │ 판매자♡│  │
│  └─────────┘  └─────────┘  └─────────┘  │
│                                         │
│         [이전] 1 / 5 [다음]             │
│                                         │
└─────────────────────────────────────────┘
```

**구성 요소**
- 헤더: 로고, 네비게이션, 사용자 정보
- 액션 영역: 보기 방식 토글, 필터, 등록 버튼
- 검색창 (sticky)
- 상품 그리드/리스트
- 찜 버튼 (각 상품)
- 페이지네이션

**동작**
- 검색어 입력 시 300ms 디바운스 후 검색
- 카드/리스트 보기 전환 (localStorage 저장)
- 상품 클릭 시 상세 화면 이동

## 공통 컴포넌트

### 헤더
- 로고 (홈 링크)
- 네비게이션 (목록, 찜, 마이)
- 사용자 이름 표시

### 찜 버튼
- 빈 하트 / 채워진 하트
- 클릭 시 즉시 UI 반영 (optimistic update)
- 실패 시 롤백

### 페이지네이션
- 이전/다음 버튼
- 현재 페이지 / 전체 페이지

### 상품 카드
- 이미지 (1:1 비율)
- 상품명, 가격, 판매자
- 찜 버튼
